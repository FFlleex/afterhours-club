# AFTERHOURS

Адаптивный сайт вымышленного компьютерного клуба в Казани. Портфолио-проект с демонстрационными тарифами и сгенерированной фотографией.

- [Открыть сайт](https://fflleex.github.io/afterhours-club/)
- Сравнение игровых зон и оборудования.
- Калькулятор стоимости по зоне, числу мест и продолжительности.
- Демобронь с проверкой даты и времени по Казани. Данные остаются на странице, оплата и реальное резервирование отсутствуют.

## Локальный запуск

В корне репозитория выполните `python3 -m http.server 8000` и откройте `http://localhost:8000/`. Сайт использует HTML, CSS и JavaScript без внешних зависимостей.

Для GitHub Pages используется ветка `main` и корень репозитория.
